# Portfólio de William Carvalho

Portfólio em português com projetos de engenharia de software, tecnologias e links de contato. A página estática usa HTML, CSS e JavaScript, com uma visualização 3D interativa renderizada em Canvas.

## Executar localmente

Na raiz do repositório, execute `python3 -m http.server 8000` e abra [localhost:8000](http://localhost:8000). O projeto funciona sem instalação de dependências ou etapa de build.

## Editar

- `index.html` contém os textos, projetos e links.
- `style.css` define a identidade visual e o layout responsivo.
- `app.js` controla a animação e a interação com o cursor.
